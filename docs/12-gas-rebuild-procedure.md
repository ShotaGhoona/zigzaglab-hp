# GAS再構築 作業手順書（お問い合わせフォーム）

## 背景
- 旧GASを管理していたGoogleアカウントが失われ、デプロイにアクセスできなくなった。
- 現状、`.env.local` の旧/新どちらのGAS URLも **403（HTMLのアクセス拒否ページ）** を返す。
  → APIルート（`src/app/api/contact/route.ts`）が `response.json()` でパース失敗し 500 になる。
- 解決策：**新しいGoogleアカウント＋新スプレッドシートでGASを作り直す**。
- 通知メール送信先：**zigzag@koyoeng.biz**
- 貼り付けるコードは `docs/gas-contact-form.js`（10項目フル対応の完成版）。

## 手順

### STEP 1. スプレッドシートを用意（✅ 作成済み）
- 新しいGoogleアカウントでスプレッドシートを作成済みとのこと。
- ※このアカウントは今後ずっと管理に使うものにする（メモを残しておく）。

### STEP 2. Apps Script を開く
1. スプレッドシートのメニュー **「拡張機能」→「Apps Script」** をクリック。
2. 新しいスクリプトプロジェクトが開く。

### STEP 3. コードを貼り付け
1. デフォルトの `コード.gs` の中身を**全部消す**。
2. リポジトリの **`docs/gas-contact-form.js`** の中身を**全部コピーして貼り付け**。
3. 💾 保存（Ctrl/Cmd + S）。プロジェクト名は「ZIGZAG Contact」などに。

> 通知先を変えたい場合は、コード冒頭の `const NOTIFY_TO = 'zigzag@koyoeng.biz';` だけ書き換える。

### STEP 4. ヘッダー行を作成（任意・推奨）
1. エディタ上部の関数選択で **`setupHeaders`** を選び、**「実行」**。
2. 初回は **権限承認**を求められる：
   - 「権限を確認」→ アカウント選択 → 「詳細」→「（安全ではないページ）に移動」→「許可」。
   - （Googleの仕様で初回のみ出る警告。自作スクリプトなので問題なし）
3. シート1行目に項目名が入ればOK。

### STEP 5. ウェブアプリとしてデプロイ ★最重要
1. 右上 **「デプロイ」→「新しいデプロイ」**。
2. 歯車 ⚙️ →「**ウェブアプリ**」を選択。
3. 設定：
   - **説明**：任意（例：v1）
   - **次のユーザーとして実行**：**自分**
   - **アクセスできるユーザー**：**全員（Anyone）** ← ★ここが今回の失敗原因。必ず「全員」。
4. 「デプロイ」→ 権限承認（STEP 4で済んでいれば不要）。
5. 表示される **ウェブアプリのURL（.../exec で終わる）をコピー**。

> ⚠️ 「アクセスできるユーザー」が「自分のみ」だと、サーバーからのPOSTに対し403のHTMLが返り、今と同じ500エラーになる。必ず「全員」。

### STEP 6. 動作確認（GAS単体）
やり方A（おすすめ）：エディタで関数 **`testRun`** を選んで実行 → シートに1行追加され、`zigzag@koyoeng.biz` に通知メールが届けばOK。

やり方B（URL疎通確認）：ブラウザでコピーしたURLを開く → `{"status":"ok"}` が表示されればデプロイ成功。

### STEP 7. アプリ側にURLを設定
1. リポジトリの **`.env.local`** を開く。
2. `GOOGLE_APPS_SCRIPT_URL` を新しいURLに書き換える：
   ```
   GOOGLE_APPS_SCRIPT_URL=https://script.google.com/macros/s/＜新しいID＞/exec
   ```
   （古い行は削除 or コメントアウト `#`）
3. **開発サーバーを再起動**（`.env.local` の変更は再起動しないと反映されない）：
   ```
   # 起動中のサーバーを Ctrl+C で止めてから
   npm run dev
   ```

### STEP 8. フロントから最終確認
1. サイトの Contact セクションからテスト送信。
2. 成功メッセージが出る／シートに行が増える／メールが届く、を確認。

## トラブルシューティング

| 症状 | 原因 | 対処 |
|------|------|------|
| まだ500 / 403が返る | デプロイの「アクセスできるユーザー」が全員でない | STEP 5をやり直し（既存デプロイは「デプロイを管理」→編集で変更可） |
| 500のまま変わらない | dev サーバーが古いenvのまま | サーバー再起動（STEP 7-3） |
| URLを開くとログイン要求 | アクセス権限が「自分のみ」 | STEP 5を「全員」で再デプロイ |
| メールが届かない | 初回の権限承認未完了 / Gmail制限 | `testRun` を実行して権限承認を完了。個人アカウントは100通/日まで |
| コード修正したのに反映されない | デプロイは「新しいバージョン」発行が必要 | 「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ |

## 補足：コード側の改善（任意）
現状 `src/app/api/contact/route.ts` は、GASがHTMLを返すと `response.json()` で落ちて「原因不明の500」になる。
`response.ok` を先にチェックしてステータスとボディをログ出力すると、次回以降の切り分けが楽になる。
